4. Answer Agent dùng chung

Nhận câu hỏi cùng bằng chứng query và/hoặc EDA sau khi các thao tác phân tích hoàn tất. Chỉ diễn giải số liệu có trong bằng chứng; làm rõ sampled, truncated hoặc operation lỗi.

Fallback: answer_template xác định khi no_data, mock, LLM unavailable/error, câu trả lời rỗng hoặc không grounded
↓
TOOL

5. Tạo biểu đồ tùy chọn

Dùng kết quả query/EDA đã có; chạy sau bước tổng hợp câu trả lời. BuildChartSpecTool chuẩn bị dữ liệu và RenderChartSpecTool tạo ảnh theo loại biểu đồ phù hợp.

Chế độ code cũ: Viz Agent sinh code, RenderChartTool thực thi; chỉ hỗ trợ kết quả query, không hỗ trợ EDA-only.

6. Kết quả: Phản hồi trong khung chat

Câu trả lời ngắn, dễ hiểu
Bảng query / kết quả EDA và SQL làm bằng chứng
Biểu đồ nếu được yêu cầu và tạo thành công

Planner đánh dấu yêu cầu biểu đồ trong kế hoạch; phần tạo ảnh chạy riêng sau Answer Agent và không thay thế câu trả lời/bằng chứng.

Planner lập kế hoạch; query và EDA chạy theo kế hoạch rồi gom bằng chứng. Answer Agent dùng chung để diễn giải; biểu đồ là nhánh tùy chọn độc lập từ kết quả phân tích.
