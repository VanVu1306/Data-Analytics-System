# 📊 A Friendly Data Analytics Chatbot

### Turn questions into insights — no SQL required! ✨

This is a lightweight app for chatting with your data. Ask questions in plain English or Vietnamese, get answers with result tables, and create charts whenever you need them. Start with the sample data or upload your own dataset. 🚀

> 💬 Ask a question → 🧠 Let AI analyze → 📋 Review the results → 📈 Explore with charts

## 🌟 What can you do?

- 💬 **Chat with your data:** ask questions in plain English or Vietnamese.
- 📋 **Get evidence with your answers:** results include a data table, and you can inspect the SQL query.
- 📂 **Bring your own data:** upload CSV, Excel (`.xlsx`, `.xlsm`), or SQLite (`.db`, `.sqlite`, `.sqlite3`) files.
- 🔎 **Explore your dataset:** review table overviews, data quality, statistics, and correlations.
- 📈 **Create charts when you need them:** request a chart in your question; charts are not generated unless requested.
- 🔗 **Connect tables deliberately:** define table relationships to support joined analysis.
- 🧪 **Try the demo flow:** some flows can run with mocks without calling an LLM.

## 🧩 How does it work?

```text
Browser
   │
   ▼
Streamlit (frontend/) ── HTTP/JSON ──► FastAPI (backend/)
                                           │
                                           ├── Planner / SQL / Answer / Viz agents
                                           ├── LLM clients: DeepSeek, OpenAI, Ollama
                                           ├── Tools: SQL, EDA, charts
                                           └── SQLite: sample DB and user datasets
```

The Streamlit interface sends questions to the FastAPI backend through a REST API. The backend orchestrates analysis, communicates with the configured LLM, and queries SQLite; the frontend does not access the database directly.

## 🚀 Get started on Windows

Run the following commands in PowerShell from the repository root.

### 1️⃣ Set up the environment

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If PowerShell blocks virtual environment activation, allow scripts for the current session and try again:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

### 2️⃣ Connect an AI provider (recommended)

Create a configuration file from the example:

```powershell
Copy-Item .env.example .env
```

Open `.env`, choose a provider, and add the corresponding API key. For DeepSeek:

```dotenv
LLM_PROVIDER=deepseek
DEEPSEEK_API_KEY=your-deepseek-api-key
```

Or choose OpenAI:

```dotenv
LLM_PROVIDER=openai
OPENAI_API_KEY=your-openai-api-key
```

🔐 Do not commit `.env` or API keys to Git. See `.env.example` and `backend/config.py` for additional configuration options.

### 3️⃣ Prepare the sample database

If `demo_db/sales_demo.db` does not exist, create the sample database:

```powershell
python scripts/create_demo_db.py
```

⚠️ This command recreates the sample database. Do not run it if you want to keep the existing demo data.

### 4️⃣ Start the application

Open **Terminal 1** to start the backend:

```powershell
.\.venv\Scripts\Activate.ps1
uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Open **Terminal 2** to start the frontend:

```powershell
.\.venv\Scripts\Activate.ps1
streamlit run frontend/app.py
```

🎉 Open the Streamlit URL printed in the terminal (usually `http://localhost:8501`) and start chatting with your data!

The backend API runs at `http://127.0.0.1:8000` by default, with interactive API docs at `http://127.0.0.1:8000/docs`. If your backend runs at a different address, set `NL2VIZ_API_URL` in the frontend terminal:

```powershell
$env:NL2VIZ_API_URL = "http://127.0.0.1:8000"
streamlit run frontend/app.py
```

## 🦙 Ollama (optional)

The default chart mode (`VIZ_MODE=spec`) does not require Ollama. To use a local model to generate chart code, install Ollama, pull a model, and add the following settings to `.env`:

```dotenv
OLLAMA_BASE_URL=http://127.0.0.1:11434
OLLAMA_MODEL=llama3.2
VIZ_MODE=code
```

On Windows, you can run `scripts/setup_ollama.ps1` after installing Ollama. Note: `code` mode executes chart code generated by an LLM, so use it only in a trusted environment.

## 🔌 Main API endpoints

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/health` | 💚 Check backend, database, and model status |
| `GET` | `/api/schema` | 🧱 Get the schema for the demo database or a dataset |
| `GET` | `/api/models` | 🦙 List installed Ollama models |
| `POST` | `/api/datasets` | 📂 Upload a CSV, Excel, or SQLite file |
| `GET` | `/api/datasets/{dataset_id}` | 🔎 Get dataset details |
| `POST` | `/api/query` | 💬 Submit a data analysis question |
| `POST` / `DELETE` | `/api/datasets/{dataset_id}/relations` | 🔗 Add or remove a table relationship |

See request and response details, or try the API at `/docs` while the backend is running. ✨

## 🗂️ Project structure

```text

  agents/       Planning, SQL, answer, and visualization agents
  api/          REST routes and Pydantic schemas

  api_client.py Backend API client
  ui/           User interface components
data/datasets/  User-uploaded datasets (managed by the backend)
demo_db/        Sample SQLite database
scripts/        Sample database and Ollama setup scripts
tests/          pytest test suite
```

## 📌 A few default limits

- 📦 Uploads are limited to **50 MB** per file.
- 🔒 Queries are read-only, with a default timeout of **10 seconds** and a result limit of **1,000 rows**.
- 🗃️ Each uploaded dataset is stored in its own SQLite database and does not modify the demo database.
- 📄 CSV, Excel `.xlsx`/`.xlsm`, and SQLite files are supported; other formats are rejected.
